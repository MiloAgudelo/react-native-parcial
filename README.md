# React Native: todos los proyectos del curso

Copia de los proyectos en un solo repo para descargarlos de una vez.
En GitHub: **Code → Download ZIP**, o `git clone https://github.com/MiloAgudelo/react-native-parcial`.

| Carpeta | Tema | Repo original |
|---|---|---|
| [`counter-app`](counter-app) | Contador, estado y componente FAB | [counter-app](https://github.com/MiloAgudelo/counter-app) |
| [`expo-calculadora`](expo-calculadora) | Calculadora | [expo-calculadora](https://github.com/MiloAgudelo/expo-calculadora) |
| [`navegacion-app`](navegacion-app) | Expo Router: stack, tabs, drawer | [navegacion-app](https://github.com/MiloAgudelo/navegacion-app) |
| [`carrito-app`](carrito-app) | Carrito con Zustand y NativeWind | [carrito-app](https://github.com/MiloAgudelo/carrito-app) |
| [`movies`](movies) | Películas con la API de TMDB | [movies](https://github.com/MiloAgudelo/movies) |
| [`maps-app`](maps-app) | Mapas y ubicación | [maps-app](https://github.com/MiloAgudelo/maps-app) |
| [`notitas`](notitas) | Supabase, autenticación y notificaciones push | [notitas](https://github.com/MiloAgudelo/notitas) |
| [`testing-app`](testing-app) | App de pruebas | [testing-app](https://github.com/MiloAgudelo/testing-app) |
| [`bases-react`](bases-react) | Bases de React + TypeScript (web, Vite) | [bases-react](https://github.com/MiloAgudelo/bases-react) |

Para correr uno: `cd <carpeta> && pnpm install && pnpm start`.
`movies` y `notitas` necesitan su `.env` con claves propias (ver `.env.example` cuando exista).
